The recorder can now capture individual outgoing hits on game versions that
provide combat-text events. Reports can credit procs, pets and summons to the
same source shown in the game's damage meter, even when the floating spell
name differs.

Capture runs in small batches with fixed storage limits. Reports warn when the
game drops events, capture starts late, or recording reaches a limit. Older
game versions continue to use combat logs. Healing capture is unchanged.

Reload the UI or restart the game after installing, then reload the UI or exit
normally after your run to save its recording. Existing recordings cannot gain
source information that was never captured.
